# Данные проектов

- `projectCatalog.json` — slug, период, полный стек (`tech`) и ключевые технологии (`keyTech`).
- `../i18n/data/<язык>/projects.json` — переводы интерфейса (`ui`) и текстов проектов (`items`). Правила: [i18n](../i18n/README.md).
- `technologyGroups.json` — группы фильтров; внутри группы названия сортируются по алфавиту.
- `../../docs/project-source-notes.txt` — исходные заметки автора, сохранённые для проверки сведений. Не импортируются в приложение.

Изображения размещаются в `src/assets/images/projects/<slug>/`: `1.png`, `2.png` и т. д. Поддерживаются PNG, JPG и WebP. Каталог автоматически подключает изображения из папки в числовом порядке. Для старых папок имя задаётся через `imageFolder`. Если изображений нет, отображается текстовая обложка. Добавление файлов требует пересборки сайта.

Главная и каталог используют общие данные. Главная сохраняет существующий выбор шести проектов и их оформление. Каталог показывает четыре проекта на странице: две колонки и два ряда на широком экране, одну колонку на телефоне. В списке показывается полный стек. Выбранные технологии объединяются условием «все выбранные». Поиск, фильтры, сортировка, вид и страница хранятся в query-параметрах URL и сохраняются при переходе в подробности и смене языка.

Периоды с `dateUncertain` приблизительные; это отмечено в подробностях. Неуверенные сведения из исходных заметок не выдаются за подтверждённые факты.
