# Переводы

Все переводы хранятся только в `src/i18n/data/<язык>/<страница>.json`.
Языки: `ru`, `ua`, `en` (код `ua` сохранён для существующих URL).

- `home.json` — главная, её секции и контактная форма.
- `gamedev.json` — страница GameDev.
- `projects.json` — `ui` для интерфейса каталога и `items.<slug>` для описаний проектов.
- `common.json` — общая навигация, переключатель режима и подписи общих компонентов.

Загрузчик `index.js` автоматически подключает эти файлы при сборке.
Для новой страницы добавьте одноимённый JSON в каждую папку языка.
Структура ключей должна совпадать во всех языках; проверка: `npm test`.

```js
t(lang, "home", "contact", "submit")
t(lang, "gamedev.hero.title")
t(lang, ["projects", "items", slug, "title"])
t(lang, "home", "contact", "errors", "count_many", { count: 3 })
```

Функция возвращает также объекты и массивы. Неизвестный язык или ключ
вызывает предупреждение в консоли, как и до разделения файлов.
Каталог, технологии и изображения без переводов остаются в `src/data` и `src/assets`.
